<h1 align="center">INE5405 · Probabilidade e Estatística</h1>

Trabalhos e atividades realizados na disciplina de Probabilidade e Estatística, no quinto semestre do curso de Ciências da Computação na UFSC.

## Competências desenvolvidas

- **Planejamento de pesquisa:** definir perguntas, coletar e organizar dados para uma análise
- **Análise exploratória de dados:** resumir, comparar e interpretar conjuntos de dados reais
- **Raciocínio probabilístico:** modelar incertezas e calcular probabilidades de eventos
- **Modelos estatísticos:** aplicar variáveis aleatórias e distribuições teóricas na descrição de fenômenos
- **Inferência estatística:** estimar parâmetros e testar hipóteses a partir de amostras
- **Automação de análises:** usar programação para processar e analisar dados


## Conteúdos abordados

- Análise combinatória
- Planejamento de uma pesquisa
- Análise exploratória de dados
- Probabilidade
- Variáveis aleatórias discretas e contínuas
- Principais modelos teóricos
- Estimação de parâmetros
- Testes de hipóteses
